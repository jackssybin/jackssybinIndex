# 不联网不登录还无水印，这个1.87万Star的开源剪辑软件，居然让AI直接帮你剪片

先说一个用剪辑软件的普遍憋屈：**好用的要订阅，免费的带水印，在线 AI 工具还要注册、把你的素材传上云。** 私密视频、客户素材，传上去心里总不踏实。

最近有个开源项目把这些坑全绕开了，叫 Concat，三个月在 GitHub 冲到 1.87 万 Star。它完全免费、本地运行、素材从不上传，更狠的是内置了一个 MCP 服务器，能让 AI Agent 像剪辑师一样直接操作时间线。我把它近 19 万行 Rust 源码扒了一遍，这篇讲清楚它到底靠不靠谱。

## 一、先看家底：近 19 万行 Rust，不是套壳小工具

很多所谓开源剪辑器就是包了一层 ffmpeg 命令，Concat 是认真做了完整架构的。我数了下：276 个 Rust 源文件、约 18.9 万行代码，拆成 18 个 crate，用一个 Cargo workspace 统一管理。

![18 个 crate 的分层架构](/root/jackssybinIndex/content-ops/concat-video-editor/media/architecture.png)

分层很清楚：主程序用 Slint 写界面、Skia 做 GPU 渲染；引擎层管解码、合成和上百种特效；能力层是抠像、语音、字幕这些 AI 功能；自动化层则是 MCP、接口和 4K 导出。引擎和界面彻底解耦，意味着它能不开窗口、在后台无头模式跑渲染。仓库里还有 187 个测试文件，发布的每个安装包都由 GitHub 自动构建、测试通过才上传，不接受个人电脑上打包的东西。

## 二、22 个 AI 模型全在本地，你的素材不出硬盘

现在剪辑器都在堆 AI，Concat 的关键区别是：所有模型都在你自己机器上跑。我读了它的模型清单，一共 22 个，分四类。

![22 个本地 AI 模型和供应链设计](/root/jackssybinIndex/content-ops/concat-video-editor/media/local-ai.png)

抠像有人物分割、通用物体、笔刷手绘蒙版，还能超分辨率放大；语音有本地文字转语音和几秒录音克隆音色；字幕靠 Whisper 本地转写，音频能做人声分离、降噪和响度均衡。

这里有个很专业的细节。模型体积比软件本身大得多，所以安装包里一个模型都不塞，等你第一次用某个功能时才下载，而且每个模型都带 sha256 校验，对不上直接拒绝运行，下载源还锁定版本、镜像到项目自己的服务器防失联。换句话说，除了你主动下载模型那一刻，剪辑全程离线，素材一个字节都不会外传。

## 三、最惊艳的：内置 MCP，AI 能替你操作时间线

这是它和所有传统剪辑软件最大的不同。它把一个 MCP 服务器直接做进了 App，你只要用一行命令把 Claude 这类 AI 接进来，它就能调用和你手动点击完全相同的剪辑能力。

![MCP 的接入方式和 Agent 工具集](/root/jackssybinIndex/content-ops/concat-video-editor/media/mcp.png)

我把文档读完了，安全设计很讲究。它分两种模式：开着软件时让 AI 走窗口模式，它不能覆盖你正在剪的工程；后台无头模式则自己拉起引擎，并用锁文件防止同一个工程被两头同时写坏。AI 生成的文件默认只能写在你的家目录，想碰别的文件夹得手动开白名单。

能力上，AI 能创建工程、导入素材、分割修剪、变速、加字幕、打关键帧、上特效，一直到带进度提示地导出成片，一共四十多个工具。而且这些工具的参数规则是从引擎代码自动生成的，文档和实际能力永远不会对不上。除了 MCP，它还提供脚本接口，源码编译后还能解锁命令行和 gRPC，方便接进自动化流水线——批量剪短视频、给播客自动切条，这下有了开源解。

## 四、基本功和五平台覆盖

去掉 AI，它作为剪辑器也够用：多轨道、画中画、关键帧曲线、磁吸时间线、上百种特效转场、标题预设，导出支持 H.264、HEVC、AV1，最高 4K 60 帧、10-bit 色深，还能用代理素材让 4K 剪辑不卡。系统覆盖苹果、Windows、Linux、安卓，iOS 走侧载，界面有 26 种语言，同一套工程文件多设备通用。

## 五、祛魅：beta 阶段和这个协议，必须想清楚

![价值与能力边界](/root/jackssybinIndex/content-ops/concat-video-editor/media/limits.png)

喜欢归喜欢，几条边界得讲明白。

第一，它还是 beta，版本号停在 0.2.x，官方自己都承认有棱角，开放的 issue 有三百多个，最近还在修切镜头出黑帧这种基础问题，重要项目别一上来就重度押注。

第二，安装有门槛。Windows 版还没买代码签名证书，会弹安全警告，甚至被系统直接拦；本地 AI 模型也吃算力，低配电脑跑起来会吃力。

第三，也是最容易被忽略的——它用的是 AGPL-3.0 协议，不是宽松的 MIT。这个协议有强传染性：你拿它做闭源软件分发要开源，**哪怕你把它包装成一个在线剪辑服务给别人用，同样触发开源义务**。想闭源商用得找作者买商业授权。当然，自己剪视频、学习、内部用，完全自由。

## 写在最后

Concat 最打动我的，是它把"本地隐私可信"和"AI 原生、Agent 可编排"在一个专业编辑器里同时做到了能用的程度。近 19 万行结构清晰的 Rust、严格的模型校验、带锁和沙箱的 MCP 设计，都说明这是奔着替代订阅制剪辑软件去的正经工程，不是蹭热点的玩具。

对注重隐私的创作者、想批量自动化剪片的开发者，它现在就非常值得上手试；但请接受它 beta 的不成熟，商用前也务必把 AGPL 协议理清楚。
