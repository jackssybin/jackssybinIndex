做AI短视频还要逐帧写Prompt？这个开源项目一次脚本输入自动生成全序列

我最近跟几个做AI内容创作的朋友聊天，发现大家都有同一个困惑。

写好脚本，还要手动拆成一个个场景，每个场景都要重新写Prompt，反复强调角色长什么样、场景色调是什么样。

生成出来，还是容易风格不统一，这帧角色长这样，下一帧脸都变了。

原来大家都觉得，AI生成越快越多越好，可实际用起来，一致性问题真的太折磨人。

直到我发现了 **OpenStory** 这个开源项目，才觉得，AI视频生成工具就该这么做。

今天这篇，我把核心用法和体验说清楚，看完你就知道要不要试试。

## 它解决了什么痛点？

我给你梳理一下传统AI做短视频的流程：

1. **写脚本** → 自己手动拆成一个个场景
2. **写Prompt** → 每个场景都要重复描述角色、场景、风格
3. **生成** → 逐个点生成，出来发现风格串了
4. **调整** → 重绘，再调整，折腾半天
5. **拼接** → 全部下载完导入剪辑软件拼接

重复劳动占了80%时间，真正用来创作的时间没多少。

OpenStory 的思路很简单：**把这些重复活全部交给AI**。

你只需要做三件事：
1. 输入完整脚本
2. 调整AI生成的结果
3. 导出成片

剩下的：拆场景、写Prompt、保风格一致性，全部自动搞定。

## 核心功能有多香？

### ✅ 脚本自动拆解

你把完整文本粘贴进去，AI自动帮你：
- 按故事拆分场景
- 给每个场景分配机位、情绪、运镜
- 提取所有需要保持连续性的元素：角色、场景、色调、灯光

不用你自己逐段处理。

### ✅ 风格自动连续

这是真的香！

OpenStory 自动提取连续性信息，每个场景生成的时候都会带上：
- 角色特征保证脸不崩
- 场景环境保证不跳戏
- 色调灯光保证整体统一

不用你每次都重复写「同一个金发女性，穿蓝色毛衣，背景是城市咖啡馆」。

### ✅ 一键生成转视频

拆解完场景，一键批量生成所有图片，然后每个图片都能一键转成动态视频。

全程在浏览器里操作，不用来回切软件。

### ✅ 团队共享资源库

团队功能还在开发中，架构已经留好了位置：
- 共享角色库：调好一个角色，整个团队都能用
- 共享风格库：保存常用的视觉风格
- 共享场景库：重复用固定地点

不用再QQ群传文件了。

## 五分钟就能本地跑起来

我亲测了，部署真的简单，只要你安装了Bun：

```bash
# 克隆项目
git clone https://github.com/openstory-so/openstory.git
cd openstory

# 安装依赖
bun install

# 一键启动
bun dev
```

就这么三条命令，剩下的自动完成：
- 自动生成配置文件
- 自动初始化数据库
- 自动启动开发服务器

打开 `http://localhost:3000` 就能用了。

然后配置两个API密钥就行：
- `FAL_KEY`：fal.ai的密钥，用来生成图片和视频
- `OPENROUTER_KEY`：OpenRouter的密钥，用来做脚本分析

交互式配置一条命令搞定：
```bash
bun setup
```

## 实际体验演示

我给你走一遍完整流程：

**第一步**：粘贴脚本
```
开场：一个程序员坐在电脑前，窗外是城市夜景，他挠头看着屏幕，表情苦恼。
切镜：特写屏幕，上面是一堆AI生成的场景图，风格各异，色调不统一。
转场：程序员打开OpenStory网站，输入同样的脚本。
收尾：生成的序列帧整齐排列，风格统一，程序员露出微笑。
```

**第二步**：点生成，AI自动拆解成4个场景

**第三步**：一键批量生成所有场景图片

**第四步**：每个场景一键转视频

**第五步**：浏览器直接导出MP4

整个过程不到五分钟，你就拿到了一个风格统一的AI视频草稿。

## 技术架构为什么说它专业？

OpenStory 用了目前最前沿的全栈架构，我给开发者划一下重点：

**技术栈清单：**
- 运行时：Bun
- 框架：TanStack Start + TanStack Router
- 数据库：Drizzle ORM + Cloudflare D1
- AI：TanStack AI + Fal.ai + OpenRouter
- 工作流：Cloudflare Workflows
- 存储：Cloudflare R2
- 认证：Better Auth（无密码Passkey）
- 样式：Tailwind v4 + shadcn/ui

最让我惊讶的是**本地开发体验**：

不需要Docker，不需要Cloudflare账号，不需要外部数据库。只要一个Bun，就能跑完全栈。Miniflare 在本地模拟了所有Cloudflare服务，开发和生产环境一致。

对于想要学习Cloudflare Workers全栈开发的同学，这个项目真的是很好的学习案例，架构清晰，代码规范，值得一读。

## 谁适合用？

如果你符合下面任意一条，我推荐你试试：

👉 你是内容创作者，经常用AI做短视频草稿，厌倦了逐帧折腾Prompt
👉 你是团队创作，需要共享角色、风格资源
👉 你是开发者，想要学习最新的TanStack + Cloudflare全栈架构
👉 你在意隐私，想要自己部署，完全掌控数据和API密钥

如果你是下面这些情况，可能暂时不适合：

❌ 你想要AI直接输出成品4K视频，不用再剪辑（目前还是序列草稿，需要二次剪辑）
❌ 你想要零成本免费生成（API费用需要你自己找fal.ai付费，项目本身免费）
❌ 你想要部署到Vercel/别的平台（目前只深度定制了Cloudflare Workers）
