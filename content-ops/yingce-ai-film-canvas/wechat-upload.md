# 58万行代码的开源AI影视工作台，上传一本小说自动做成短剧，我拆完源码讲实话

先说一个判断：**AI 视频工具的真正分水岭，不是谁的单段片更炫，而是谁能把"小说到成片"这条碎成一地的链路，接成一条能人工兜底的流水线。**

你肯定也有这感觉：写剧本一个工具、出角色图一个、生视频一个、剪辑又是一个，文件导来导去，人设还动不动就变脸。最近我挖到一个 1747 Star 的开源项目「影策」，想把这一整套收进一个工作台，还能完全自己部署。我把 58 万行源码翻了一遍，这篇不吹不黑，讲清楚它怎么做到的、门槛在哪。

## 一、先说体量：这是个平台，不是小脚本

很多所谓 AI 创作开源项目，本质是个前端页面加几个 API。影策不是。

![影策的五层全栈技术架构](/root/jackssybinIndex/content-ops/yingce-ai-film-canvas/media/architecture.png)

我数了下：后端用 Go 写的，1436 个文件、约 30 万行；前端 React + Vite，1389 个文件、约 28 万行；还自带 112 个模型插件、6 套 Docker 编排、完整管理后台和支付。58 万行的量，说明它瞄准的是"可自托管的影视生产平台"，下载即用的轻工具这个预期你先放下。

## 二、一本小说怎么变成短剧：四步流水线

它最核心的玩法，是把创作拆成四段，而且每一段你都能插手改，不是黑盒一键出片。

![从小说到成片的短剧制作流水线](/root/jackssybinIndex/content-ops/yingce-ai-film-canvas/media/pipeline.png)

第一步上传小说，自动按集拆剧本、提取角色道具场景。第二步做结构化分镜，每个镜头标好景别、运镜、时长，右边还对照着小说原文；角色生成三视图并**锁定形象，整部剧沿用同一张脸**——这点很关键，专治 AI 视频的人设漂移。第三步逐段生视频，从第二段起自动把上一段最后一帧当下一段首帧，镜头才连贯。第四步进时间线，修剪、字幕转写、服务端合成成片。

注意它的产品哲学：AI 负责执行，人负责在关键节点接管。改台词、锁角色、单段重生成，随时可以。

## 三、最有含金量的设计：112 个模型插件怎么管

这是我觉得工程上最值的部分。影策不绑定任何一家模型商，文本、图片、视频、音频全做成插件，我数了下一共 112 个。

![112 个模型协议插件与 Manifest 合同机制](/root/jackssybinIndex/content-ops/yingce-ai-film-canvas/media/plugins.png)

我专门打开一个视频插件的 manifest 配置看了，它靠一套"合同"来收编各家乱七八糟的 API 差异：统一的参数映射、写死的校验规则（比如某个模型最多 9 张参考图）、以及把五花八门的返回归一化成统一格式。换模型时上层业务几乎不用动。

安全上也克制：插件碰不到你的 Cookie、数据库和密钥，不能自己注册后端路由，出错、超时、权限不够都必须明确报错，不许偷偷降级。你的模型 API Key 始终在自己部署的环境里，不经过项目官方。

## 四、无限画布和还在内测的 3D 世界引擎

除了流水线，它还有一块无限画布，用节点把图片、视频、文本、音频、3D 预演组织起来，Agent 能结合上下文直接在画布上动手，但生成操作要过审批和额度检查，不会乱改你作品。

更前沿的是 3D 世界引擎（用 React Three Fiber 做的）：在 3D 场景里摆布景、排机位，地上标 A、B 两个点，一句话让角色从 B 跑到 A，它生成关键帧，再导出白模和深度图给视频模型当参考。不过这块官方明说还在内测，先知道方向就好。

## 五、祛魅：MIT 很香，但这些坑要先知道

![上手门槛与安全边界](/root/jackssybinIndex/content-ops/yingce-ai-film-canvas/media/limits.png)

把话说全，免得你冲动上车。

第一，**软件免费，但生成内容的模型 API 费用完全自理**，它只帮你管渠道不帮你买单，量产视频成本不低。第二，本地跑起来需要 Bun、Go 1.25 和 Docker，有运维门槛，不是双击安装。第三，项目还在高速迭代，数据结构和接口可能变。

安全这块必须划重点：官方明确说默认只适合个人、本地或可信环境，**别不做配置就直接挂公网**。要关开放注册、CORS 不能用通配符、后端默认拦截私网地址防 SSRF、密钥不能进日志。官网那个 test 演示账号只供体验，别放敏感东西。

许可倒是真友好，MIT 协议，商用和二开都宽松，比 AGPL 省心。

## 写在最后

影策真正解决的，是把过去散落在十几个软件里的 AI 影视环节，收敛成一个数据互通、能人工接管、能完全私有部署的工作台；而 112 个插件背后的合同设计，让它不会被单一模型商绑死。

但它是给有技术能力的创作者和小团队的"平台骨架"，不是零门槛的免费成片魔法——你得能驾驭 Docker、愿意自付模型费用、接受它还在演化。想试的话，建议先用官网在线演示摸一遍流程，再决定要不要本地搭。
