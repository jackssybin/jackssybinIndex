# 不注册不留Key的浏览器AI试衣间，这个108Star小项目把隐私做到了源码里

先说一个很多人没意识到的风险：**你用那些 AI 试穿工具时填的 API Key、传的真人照片，大概率经过了别人的服务器。**

AI 试穿这两年很火，但多数产品要么逼你注册、把照片和密钥交出去，要么是个黑盒套壳，背后干了啥你根本看不见。最近我挖到一个反着来的开源小项目「衣姿 PoseWear」，刚 108 Star，纯静态、不要后端、密钥全程只待在你自己浏览器里。我把源码逐行看了一遍，这篇讲讲它怎么做到的，以及一个很容易踩的版权坑。

## 一、它是什么：一个会生图的参考图库

先厘清定位，它不是大模型，也不是传统 SaaS，而是个部署在 Cloudflare Pages 上的静态站，由两块组成。

一块是三套参考图库：姿势线稿、1439 个深度姿势（还带日文原名）、分类服装，加上 CC0 协议的人像脸模，每张图都配了可直接复制的中英文提示词。另一块是试穿工作台：传你自己的照片、挑服装和姿势、配上模型 API，就能出试穿图，支持多张、前后对比和打包下载。

![一次 AI 试穿的完整流程](/root/jackssybinIndex/content-ops/posewear-ai-tryon/media/flow.png)

服务商支持四家：OpenAI、Gemini（就是 Nano Banana）、豆包 Seedream，还有任何 OpenAI 兼容的自定义中转。

## 二、技术栈意外地克制：原生 JS，零框架

现在随便一个前端项目都是 React 全家桶，这个项目却复古得清爽。我看了源码目录，前端就是原生 HTML、CSS、JavaScript，没有任何框架，核心几个 JS 加起来才一千来行；离线靠 Service Worker，还能装成 PWA。

构建用 Python 生成缩略图、详情页和安全头，测试用 Playwright 模拟各种报错，连真实 Key 都不需要。这种"够用就好"的做法带来一个直接好处：**你想知道它拿你数据干了什么，读那几个文件就能查清楚，可审计性很强。**

## 三、隐私不是口号，是写进代码的四道防线

这是我最想讲的部分。一个要你填 Key、传真人照的工具，隐私是底线，我核对了实际实现，确实有东西。

![密钥、代理、CSP、本地存储四层安全设计](/root/jackssybinIndex/content-ops/posewear-ai-tryon/media/security.png)

第一，**密钥不上服务器**，Key 只存浏览器本地，默认浏览器直连厂商官方接口，设置里能一键清除。

第二，**可选代理有四道闸**。只有你手动开代理、或用豆包（它不允许浏览器跨域）才会经过它的代理函数。我读了代理源码：校验请求必须同源、只转发官方域名白名单、拒绝内网地址、还按 IP 限流，注释明说"只转发、不记录、不存密钥"。

第三，**严格的 CSP 安全头**，把能联网的域名锁死在那几家厂商，禁止插件、禁止别人用 iframe 嵌套，脚本还走哈希白名单，就算被注入恶意代码也难把数据发出去。

第四，**数据全在本机**，收藏、历史都存浏览器的 IndexedDB，没有账号、没有后端数据库，自然无从泄露。

## 四、"减少误拦截"：一张讲究的双语替换表

真人照配泳装、内衣，最容易撞上内容审核。它默认开了个"减少误拦截"功能，思路很妙。

![敏感词如何中性化成电商措辞](/root/jackssybinIndex/content-ops/posewear-ai-tryon/media/neutral.png)

源码里是一套中英文正则替换表，**只改发给模型的措辞，绝不碰你选的服装和姿势**。比如"性感、火辣"换成"时尚"，"低胸"换成"V 领"、"露背"换成"开背设计"，"比基尼"换成"泳池边时装"，"裸露"这类词直接删掉，最后套上一段专业电商试穿的框架描述。

分寸感在于：它只降低正常穿搭被误判的概率，**不帮你绕过对真正违规内容的审核**，而且能一键关闭、按原文发送。

## 五、祛魅：好用，但这几个坑要先知道

![适用场景与能力、版权边界](/root/jackssybinIndex/content-ops/posewear-ai-tryon/media/limits.png)

使用门槛上，仓库**不含任何图片素材**，想自己部署得先跑脚本从原站下载，数据好几个 G；生成费用按你选的服务商从自己账户扣，它本身不收费；审核方面 OpenAI 最严，Gemini 和豆包宽松些。

最关键的是版权，这点一定分清：**MIT 协议只覆盖代码，不覆盖图片。** 姿势和服装图版权归原作者，原站没标开放许可，想商用或转载必须先联系授权；深度姿势图是热链原站、根本不在仓库里；只有人像是 CC0 可商用，但原作者希望别原样批量转载，也不能拿 AI 虚构人脸冒充真人。

另外它 10 月底才建仓，还很年轻，部分路线图功能没做完。

## 写在最后

这个项目打动我的不是功能多炫，而是克制和坦诚：用原生代码把可审计性拉满，把密钥和数据死死按在用户本地，把安全规则摊开给你看，连素材版权边界都写得明明白白。

对需要快速出穿搭参考、又不放心把照片交给陌生平台的电商、自媒体和设计师，它顺手又安心；纯静态站自部署成本也极低。但记住它是轻量参考工具，素材授权和模型费用还得自己把关。
