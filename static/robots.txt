User-agent: *
Allow: /

# ── 只屏蔽「永远不需要被抓取」的路径 ──────────────────────────────
# 判定原则：想让一个页面从索引里消失，要让它可抓取 + 页面自带 noindex。
# 如果这里 Disallow，爬虫取不到页面，也就读不到 noindex 标签，
# 页面反而会长期滞留在索引中，在百度/Google 里显示成
# 「由于 robots.txt 限制，无法提供描述」——比不收录更难看。
#
# 下列页面已全部输出 <meta name="robots" content="noindex, follow">，
# 因此不再在这里 Disallow：
#   /tags/*  /tags.html   /page/*  /news.html  /weekly.html
#   /topics.html  /nav.html  /ai-nav/*
Disallow: /search
Disallow: /search.html
Disallow: /search-index.json
Disallow: /admin/
