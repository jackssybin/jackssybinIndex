> **TL;DR**：`AI_COMIC` 是一个国人开源的全流程AI漫画生成工作台，使用 DeepSeek 生成分镜剧本，通义千问 Qwen-Image 生成逐格画面，浏览器内编辑对白、排版、导出长图。完全本地运行，API Key 不会泄露。适合想自己创作AI漫画又不想折腾多个工具的同学。

## 项目简介

最近AI绘画火了，但想做一整篇完整漫画，你得：
1. 自己写剧本分镜
2. 用Midjourney逐张生成
3. 用Photoshop排版加对白
4. 错了还要重来

整个流程折腾下来，大半天就没了。

这个刚发布三天的国产开源项目 **AI_COMIC** 直接把全流程自动化了：**你只需要输入故事idea，它自动帮你生成结构化分镜，然后逐格生成画面，最后在浏览器里编辑导出PNG长图**。

项目地址：https://github.com/nfzwycwmxz/AI_COMIC

Star 虽然只有 1 个，但功能已经完整可用，思路非常清晰，解决了真实痛点。

## 核心工作流程

整个流程就是四步，全部在本地完成：

```
输入故事idea
    ↓
DeepSeek 生成结构化分镜（格数×对白×描述）
    ↓
Qwen-Image 逐格生成画面
    ↓
浏览器编辑 → 导出PNG长图
```

### 关键优势

1. **全流程一站式** — 不用来回切换ChatGPT、Midjourney、PS，一个工具搞定从idea到导出
2. **完全本地运行** — API Key 只在本地Node服务读取，不会上传到第三方，安全放心
3. **可编辑** — 生成分镜后可以随时修改对白、重绘单格，不是生成完就不能改
4. **保存项目** — 可以保存当前进度，之后继续编辑，不用从头再来
5. **配置灵活** — 支持自定义API地址、模型、图片尺寸，适配不同账号区域

## 配置要求

要跑起来，你需要准备这三样：

| 依赖 | 说明 |
|------|------|
| Node.js 20+ | 运行本地服务 |
| DeepSeek API Key | 用来生成分镜剧本 |
| 阿里云百炼 DashScope API Key | 开通 `qwen-image-2.0-pro` 用来生成画面 |

如果你没有DashScope，但有OpenAI兼容的图片生成API，也可以用——服务端会根据URL自动选择请求格式，改成OpenAI图片接口地址就行。

## 五分钟快速启动

### 1. 克隆安装

```bash
git clone https://github.com/nfzwycwmxz/AI_COMIC.git
cd AI_COMIC
npm install
```

### 2. 配置API Key

```bash
cp .env.example .env
# 编辑 .env 文件，填入你的 API Key
```

`.env` 关键配置：

```env
DEEPSEEK_API_KEY=your-deepseek-key-here
QWEN_API_KEY=your-dashscope-key-here
# 如果你用OpenAI兼容接口改这里：
# QWEN_API_URL=https://api.openai.com/v1/images/generations
# QWEN_IMAGE_MODEL=dall-e-3
```

### 3. 启动

```bash
npm start
```

浏览器打开 `http://127.0.0.1:4173` 就能用了。

开发调试用 `npm run dev`。

## 使用体验

我体验了一下整个流程，说下实际感受：

### 优势

- **思路清晰** — 把大语言模型的分镜能力和图像模型的绘画能力串起来，解决了真实痛点
- **界面简洁** — 三步操作：输入 → 生成 → 导出，没有花里胡哨的功能
- **隐私安全** — API Key 只在本地，不会泄露，项目文件存在本地，不用担心内容被上传
- **导出方便** — 直接导出 PNG 长图，拿到就能用

### 局限性

- **依赖 Qwen-Image-2.0-Pro** — 这个模型目前只有阿里云百炼有，需要开通相应服务
- **不能训练风格** — 就是直接调用API生成，没有LoRA风格训练，如果想要特定画风需要提示词控制
- **国产项目刚发布** — Star 少，可能有bug，遇到问题可以去GitHub提issue

## 适合谁，不适合谁

✅ **适合这些同学**：
- 想创作自己的AI漫画，不想折腾多个工具
- 有故事idea，但不会画画也不会排版
- 看重隐私，不想把故事内容传给第三方平台
- 本地折腾党，喜欢自己搭工具玩

❌ **不适合这些同学**：
- 没有API Key又不想申请
- 想要现成的模型离线跑，不想调用API
- 想要商业级印刷质量，这个还是AI生成，达不到专业画师水平

## 我的使用建议

1. **故事idea给得越具体越好** — 给AI的prompt越详细，分镜生成越符合预期，比如"一个少年在森林里捡到一只会说话的狐狸"比"奇幻故事"好。

2. **不用一次生成全部** — 先生成分镜，检查一下对白对不对，不满意可以改，没问题再批量生成全部画面，省API调用次数。

3. **单格不满意直接重绘** — 哪一格生成效果不好，直接点那一格的"重新绘制"，不用重来。

4. **导出前先预览** — 在"成页"视图看好排版和对白位置，不对再调，然后导出。
