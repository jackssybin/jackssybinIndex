# oh-story - 专为 Claude Code 打造的网文写作全流程 AI 技能包

如果你想用 AI 辅助写网络小说，大概率会遇到这些问题：

- 写着写着人设崩了：上一章主角还住宿舍，下一章直接从家里出门
- AI 味太重：句式工整得不像真人写的，读者一眼就能看出来
- 错字漏字频频：固定搭配写错了自己还发现不了
- 伏笔埋了就忘：前面挖的坑后面填不上，读者追更体验差

今天给大家介绍一个非常实用的开源项目 —— [oh-story](https://github.com/qin1473692580-ux/oh-story-claudecode)，它把网文写作从扫榜、拆文、写作到去 AI 味、质检的全流程，都做成了 Claude Code 等 AI Agent 可直接使用的技能包，真正解决了普通人用 AI 写网文的痛点。

## 项目是什么？

oh-story 是一个网文写作 skill 包，覆盖长篇与短篇网络小说的扫榜、拆文、写作、去AI味、封面图全流程。内置适配了 Claude Code、OpenCode、ZCode、OpenClaw、Codex CLI、Reasonix、workbuddy 等主流 AI Agent 环境，能读取项目文件的 Web AI / Agent 环境也可按通用 skills 路径使用。

本仓库是 oh-story 的现役独立产品仓库和发行线，所有功能都经过实战验证 —— 作者自己用这套工具写出了正在番茄小说连载的长篇《[财阀除名那晚，古井给我递了药方](https://fanqienovel.com/page/7661645008545516606)》，所有改进都来自真实写作复盘，把实战中踩过的坑改回了工具本身，而不是每次靠人工记住。

## 核心优势：从实战踩坑中沉淀的自动化机制

oh-story 不是简单把写作提示词丢给你就完事了，它在传统写作流程基础上，增加了很多从实战中总结出来的自动化检查机制：

### 1. 错别字校验前置门

新增 `check-typos.js`，作为每章写完落盘后的第一道检查（先于AI味/退化/标点脚本）—— 源自作者真实漏检案例（"那笔钱"误写"那笔欠"被读者发现）。内置高置信度固定搭配词典，只提示不自动改写，不会误伤专业术语或特殊表达。

### 2. 反转规则消歧

原来很多教程说"一个反转撑一篇"，很容易被误读成整篇只需要一个大反转。oh-story 根据真实爆款语料修正为："一个核心反转撑骨架，高频小反转做肌肉"，建议每 800-1500 字就有一次小翻转，保持读者的阅读粘性。

### 3. 连续性检查机制

最常见的网文硬伤就是上下文不一致。oh-story 实现了**跨章连续性守卫**：位置、持有物进热上下文，改动必须逐字报出旧值才放行，直接堵住「上一章住宿舍、下一章骑车从家出发」这类低级硬伤。

### 4. 去 AI 味自动化检查

除了常规的去 AI 味规则，oh-story 还实现了**毒句式欠账门**机制：写后正文会自动扫描确定性的 AI 常见句式，写下一章前会自动检查上一章有没有没修正的 AI 句式，避免问题积累。

### 5. 多题材包支持

除了传统的追妻火葬场、复仇打脸、总裁豪门、宅斗宫斗四个题材包，新增了两个实战验证的高热度题材包：

- **现实共鸣型**：原生家庭剥削/职场PUA反杀/彩礼陷阱，完全基于番茄作家后台真实热门故事榜语料验证
- **悬疑脑洞型**：死亡游戏/规则怪谈，包含创作五步法与真规则原则，已经用于实际成稿

## 完整流程覆盖

oh-story 覆盖了网文写作从准备到出稿的全流程：

**环境部署阶段**
- `/story-setup`：一键部署环境，支持多种 CLI 适配

**扫榜选材阶段**
- `story-long-scan`：长篇扫榜，分析起点/番茄/晋江市场趋势
- `story-short-scan`：短篇扫榜，采集知乎盐言/番茄短篇风口数据

**拆文学习阶段**
- `story-long-analyze`：长篇拆文，分析黄金三章、爽点设计、节奏
- `story-short-analyze`：短篇拆文，分析故事核、结构、反转设计

**落笔创作阶段**
- `story-long-write`：长篇写作，大纲搭建、人物设定、正文输出
- `story-short-write`：短篇写作，情绪设计、反转构思、精修出稿

**精修定稿阶段**
- `story-deslop`：去 AI 味，检测并清除 AI 写作痕迹
- `story-review`：多视角审查，4 Agent 多视角审稿 + 番茄/起点/知乎评分标准
- `story-cover`：封面生成，书名题材分析 + GPT-Image-2 出图

## 多 Agent 专业分工体系

oh-story 内部通过 7 个专业 Agent 协作，各司其职，保证产出质量：

- **story-architect**：故事架构 —— 题材定位、大纲结构、钩子/反转设计、情绪弧线
- **character-designer**：角色设计 —— 角色档案、语言风格、动机链、对话创作
- **narrative-writer**：叙事写手 —— 正文写作、去AI味、格式合规
- **consistency-checker**：一致性检查 —— 事实冲突扫描、伏笔追踪、分级报告
- **story-researcher**：资料研究 —— CDP 搜索+正文提取、多源交叉验证、结构化参考输出
- **story-explorer**：故事查询 —— 角色/伏笔/设定/进度只读查询，日更上下文快速加载
- **chapter-extractor**：章节提取 —— 摘要+情节点+角色提及，并行拆文核心单元

每个 Agent 按需加载 references 中的写作理论（100+ 份方法论文件），不预占上下文。

## 自动化 Hooks 保障质量

Claude Code 项目经 `/story-setup` 部署后会启用 8 个 shell hook，在写作过程中自动帮你检查问题：

| Hook | 触发时机 | 功能 |
|------|----------|------|
| session-start.sh | 会话开始 | 显示分支、进度快照、拆文状态 |
| session-end.sh | 会话结束 | 记录会话日志 |
| detect-story-gaps.sh | 会话开始 | 检测设定缺口、大纲缺失、伏笔断线 |
| pre-compact.sh | 上下文压缩前 | 保存进度快照 |
| post-compact.sh | 上下文压缩后 | 提示恢复进度 |
| validate-story-commit.sh | git commit | 检查硬编码属性、设定必填字段 |
| guard-outline-before-prose.sh | 写正文前 | 缺细纲阻止创建正文，强制先搭大纲 |
| check-prose-after-write.sh | 正文落盘后 | 兜底扫描 AI 常见毒句式 |

## 清晰的项目文件结构

一部长篇动辄几十万字、几百章，oh-story 用文件系统把设定、大纲、正文、追踪拆开，每个维度独立维护，告别"写到最后全靠记忆硬撑"：

```
{书名}/
├── 设定/
│   ├── 世界观/          # 按主题拆文件
│   ├── 角色/            # 每个人物一个文件
│   ├── 势力/            # 每个势力一个文件
│   ├── 关系.md          # 角色关系映射
│   └── 题材定位.md      # 题材核心梗+对标分析
├── 大纲/
│   ├── 大纲.md          # 全书卷级结构
│   ├── 卷纲_第一卷.md   # 每卷一个：爽点节奏+情绪弧线+伏笔+反转
│   ├── 细纲_第001章.md  # 每章一个：内容概括+多线情节+出场顺序+钩子
│   └── ...
├── 正文/
│   ├── 第001章_章名.md
│   └── ...
├── 对标/                # 对标参考（从拆文库同步）
│   └── {对标书名}/
│       ├── 原文/
│       ├── 角色/
│       ├── 剧情/
│       ├── 设定/
│       ├── 文风.md
│       └── 拆文报告.md
├── 追踪/                # 连续性管理
│   ├── 上下文.md        # compact 恢复用
│   ├── 伏笔.md          # 伏笔埋设/回收状态表
│   ├── 时间线.md        # 故事内时间线（全书级）
│   └── 角色状态.md      # 角色当前状态快照
├── 参考资料/            # 研究资料
│   └── {topic}.md       # 按主题拆分
```

这种结构化的文件管理方式，即使你写了几百章，也能快速找到需要的信息，不会出现前后矛盾。

## 支持多平台安装

oh-story 支持多种主流 AI Agent 环境，安装方式非常简单：

### 方式一：直接在 Claude Code 中安装

告诉 Claude Code：
```
安装这个 skill https://github.com/qin1473692580-ux/oh-story-claudecode/releases/latest/download/oh-story-release.zip
```

### 方式二：命令行安装

```bash
npx skills add https://github.com/qin1473692580-ux/oh-story-claudecode/releases/latest/download/oh-story-release.zip -y -g
```

`-g` 表示全局安装，所有目录可用；去掉 `-g` 则只装到当前目录。这个 URL 始终指向最新的正式 GitHub Release 资产，不会把开发态的 `main` 分支安装到你的环境，保证稳定性。

### 支持的平台

- Claude Code：原生支持，完整 hooks 和 custom agents
- OpenCode：全局安装后自动发现，部署后退出重进即可使用
- ZCode 3.3.4+：原生适配
- OpenClaw：skills-only 支持
- Reasonix：原生 plugin 支持
- 通用 Web AI：解压后直接读取技能文件

## 本地写作工作台

部署完成后，在项目根运行 `/story dashboard` 即可启动本地工作台：

- 浏览拆文库和写作项目
- 搜索文件
- 安全编辑白名单文本格式
- 保存采用版本校验，删除需要确认
- 只监听 `127.0.0.1`，不会自动暴露到公网

非常适合日常管理你的写作项目。
